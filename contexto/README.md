# contexto/

Insumos originales del cliente con los que se levantó el requerimiento de **Synatrack**.
**No es código**: nada de esta carpeta se compila, se importa ni se usa en tiempo de ejecución.

| Archivo | Qué es |
|---|---|
| `REQUERIMIENTO_DESARROLLO.docx` | Requerimiento funcional original. |
| `Conversacion.docx` | Notas de la conversación inicial con el cliente. |
| `Plantilla_Monitoreo_Presupuesto_TI_Completa2.xlsx` | Plantilla de monitoreo de presupuesto de TI usada como referencia. |
| `SY_6.html` | Maqueta/entregable en HTML (~97 KB). |

## Antes de compartir el repositorio

Son **documentos comerciales del cliente** y pueden contener información confidencial
(nombres, cifras, condiciones contractuales). Antes de dar acceso al repositorio a alguien
externo, o de publicarlo, hay que revisar este contenido y decidir si se mueve fuera del
control de versiones.

No se borra nada por ahora: esta carpeta es la trazabilidad del origen del proyecto.
Registrado como DEP-28 en `documentacion/BACKLOG_DEPURACION.md`.
